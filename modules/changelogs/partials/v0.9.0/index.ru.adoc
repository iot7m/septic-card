= История изменений
:description: История изменений Septic Card — новые возможности, улучшения и исправления для Home Assistant.
:keywords: Septic, Home Assistant, история изменений, changelog, версии, обновления, кастомная карточка
:navtitle: Версия v0.9.0

Версия 0.9.0 посвящена расширению функциональности и повышению стабильности карточки. В рамках релиза добавлена поддержка новых параметров, устранены проблемы layout в режимах masonry, sections и однострочном размещении, а также обновлена документация и раздел установки через HACS.

Changelog:

- Добавлен сенсор уровня сигнала SDT
- Добавлен бинарный сенсор превышения критического уровня
- Реализовано отображение ошибки септика
- Добавлены тесты для проверки логики обработки ошибок
- Добавлены тесты для функции локализации
- Обновлены entity-тесты
- Исправлены ошибки layout для режимов `masonry` и `sections`
- Исправлено отображение карточки в однострочном layout
- Обновлён README после публикации карточки в HACS
- Обновлён раздел установки через HACS в документации
