= История изменений
:description: История изменений Septic Card — новые возможности, улучшения и исправления для Home Assistant.
:keywords: Septic, Home Assistant, история изменений, changelog, версии, обновления, кастомная карточка
:navtitle: Версия v0.0.4

Версия v0.0.4 посвящена генерализации карточки и подготовке её к использованию с любыми септиками и аналогичными системами. В рамках данного релиза была переработана конфигурация карточки, обновлена документация, улучшен внешний вид, а также внесены изменения, необходимые для масштабирования решения на несколько объектов.

Changelog:

- выполнена генерализация логики карточки для работы с любыми септиками
- обновлена и унифицирована структура конфигурации и значения по умолчанию
- обновлены стили карточки для улучшения визуального восприятия
- изменена иконка параметра `x_level`
- удалена устаревшая функция `getEntityId`
- удалён отладочный лог
- добавлена поддержка алиаса импорта `@/`
- внедрена поддержка локализации
- добавлены тесты для функции локализации
- обновлены изображения и скриншоты карточки
- добавлен тестовый dashboard септика для проверки обобщённой карточки
- обновлён README с учётом унифицированной модели конфигурации
