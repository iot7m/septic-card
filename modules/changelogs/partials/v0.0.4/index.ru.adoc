:navtitle: Версия v0.0.3

Версия v0.0.3 посвящена подготовке карточки к корректному распространению через HACS. В рамках данного релиза были устранены проблемы совместимости с требованиями HACS, доработаны значения конфигурации по умолчанию и выполнен внутренний рефакторинг логики работы с настройками карточки.

Changelog:

- выполнена подготовка репозитория к публикации в HACS
- откорректирован файл hacs.json в соответствии с требованиями HACS
- устранены проблемы валидации структуры репозитория при установке через HACS
- добавлены значения конфигурации по умолчанию для карточек
- выполнен внутренний рефакторинг логики работы с конфигурацией
