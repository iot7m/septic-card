:navtitle: Version v0.0.3

Version v0.0.3 focuses on preparing the card for proper distribution via HACS. This release resolves compatibility issues with HACS requirements, introduces default configuration values, and includes an internal refactor of the configuration handling logic.

Changelog:

- prepared the repository for publication in HACS
- updated the hacs.json file to comply with HACS requirements
- fixed repository structure validation issues during installation via HACS
- added default configuration values for cards
- performed an internal refactor of the configuration handling logic
